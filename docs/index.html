01 / THE CONCEPT

Hai hướng truyền.
Một trải nghiệm.

Điện thoại người dùng không cần gói dữ liệu Internet. Gateway và đài phát vẫn cần hạ tầng riêng để lấy nội dung và phát tín hiệu.

Android → SMS → Gateway

03 / TECHNICAL ARCHITECTURE

Đường đi của dữ liệu.

Mô hình phản ánh các thành phần đang có trong mã nguồn nghiên cứu. Một vài tích hợp chỉ hoạt động trên thiết bị phù hợp.

SMS request

02 / GATEWAY

Manager

Nhận SMS bằng USB dongle, xử lý queue và cache.

03 / RENDER

Web / AI

Selenium → screenshot 320px, hoặc OpenAI API.

04 / AUDIO

Encode

MDTA, C137, SDTA → Quiet WAV → FM station.

05 / RX

Decode

Kiểm lỗi, khôi phục ảnh và lưu SQLite trên Android.
